## 复刻要点

- 背景由 `WallpaperPanel` 运行时选择，不存储在 `imgBackGround` 的 prefab-time `Image.sprite` 上。
- `btnGal`、底部导航栏、右侧充值/商店/月卡、左侧活动区都属于 `MainUIView`，不是 `CityView`。
- `pnlCommercialization` 和 `svRes` 使用 prefab bundle 内置的 `Background` sliced Sprite；`btnTask`、`btnDevelop`、`btnBodyMask` 使用内置 `UISprite` 透明/切片 Sprite。

## 修正经验

- PowerShell 查看 UTF-8 文档时显式设置输出编码，避免中文显示成 `?`：

```powershell
[Console]::OutputEncoding = [System.Text.UTF8Encoding]::new($false)
$OutputEncoding = [Console]::OutputEncoding
Get-Content -Encoding UTF8 -Path docs\shaonv-mainui-full-control-resource-inventory-2026-05-24.md
```

- 生成文档时不要把中文说明文本放进 PowerShell here-string 再交给 Python 写入；这条链路可能把脚本文字变成 `?`。更稳的做法是用 `apply_patch` 写中文说明，或让 Python 只写从 UTF-8 JSON 读取出来的原始中文文本。
- `MainUIView.mb-fields.json` 的 `imagesUnresolvedExternal=18` 不代表资源缺失。处理顺序应是：先查 prefab bundle 内部 Sprite，再按 SerializedFile external 顺序把 `m_FileID` 映射到 CAB，最后用物理资产表反查 `bundleName/hashFileName/physicalPath`。
- `imgBackGround` 的 `Image.sprite` 为空是正常现象，不能据此判断主界面没有背景图。背景由 `WallpaperPanel` 运行时选择，截图实证对应 `Assets/Game/RawAssets/Sprite/BackGround/mainui_bg_01.png`。
